# Apple Stocks local market-data research

This directory documents REA-based inspection of the locally installed macOS
Stocks application. The integration is read-only; it does not call the private
StocksKit XPC service, use authentication tokens, or alter Apple files.

## REA findings (macOS 26.7 / Stocks 8.5)

- REA `inspect-macho` identified the Stocks app and the StocksKitService XPC
  executable, both linking `StocksCore` and `StocksKit` private frameworks.
- REA `inspect-native-dispatch-metadata` found the StocksKitService `Assembly`
  type, but no stable public API contract for requesting quotes.
- REA `inspect-sqlite-database` identified SQLite tables `quotes`,
  `quote_details`, `stock_metadata`, and `sds_auth_tokens` in the read-only
  `shared-database`, plus `sparklines` in `sparkline-database`.
- **Never inspect or copy `sds_auth_tokens`.** The adapter only reads quotes
  and sparklines. The underlying databases and their WAL files stay in place.
- A quote is stored as JSON `{"v": {"price": ..., "priceChange": ...,
  "dateLastRefreshed": ..., "exchangeStatus": ...}}`.
  `updatedAt` uses Unix seconds; `dateLastRefreshed` uses Apple reference date
  seconds (epoch 2001-01-01). Add 978307200 seconds for Unix time.
- A sparkline is JSON `{"v": {"entries": [{"referenceDate": ..., "open": ...,
  "high": ..., "low": ..., "close": ..., "volume": ...}]}}`.
  Most observed bars are 10 minutes wide, so they are only used for intervals
  that can correctly aggregate 10-minute bars (30m, 1h, 4h).

## Symbol refresh discovered through REA + live validation

REA `inspect-plist` confirmed that Stocks 8.5 registers the `stocks` deep-link
scheme (evidence `ev_84db0e445c7410ae44c0181976b16a8b67332b40816b650c80d874a9d900cf25`).
Apple's published Apple News Format documentation describes
`stocks://?symbol=SYMBOL` as a link to a ticker in Stocks.

On this Mac, `open -g 'stocks://?symbol=ORCL'` caused a previously missing
`quotes` row to appear in the Stocks cache in about one second. The new
Terminal router then fetched a previously uncached ADBE quote by asking
Stocks to open it and returning the new cached data. A further end-to-end
test of `035900.KQ` verified the same workflow for a Korean KOSDAQ equity:
the local quote cache had 0 matching records before the request and 1 after.

The implementation now automatically does: cache lookup, open Apple's
registered symbol URL in the background when absent/stale, poll the read-only
cache for up to 4 seconds, then return to Yahoo if Apple did not deliver data.
Concurrent opens for the same symbol are coalesced. Other symbol opens are
spaced apart and failed symbols are subject to a 120-second retry cooldown.
Opening a symbol may change the selected symbol within Apple's Stocks app,
but does not intentionally change watchlists or place trading orders.

## Access constraints

The caches contain **only securities fetched by Apple Stocks**, but the new
deep-link path can request that Stocks display and fetch a previously unseen
symbol. The app/service decides whether and when data actually arrives.
Not every symbol is supported, and the returned prices may be delayed.
Missing or stale records fall back to the terminal's standard sources. Apple
private cache formats may change with macOS updates.

In Apple-cache mode, Terminal deliberately disables its ordinary synthetic
sample fallback: if both Apple's cache and Yahoo have no quote, no fabricated
stock price is shown. Use `TR_PROVIDER=sample` explicitly for an offline demo.

No downloaded Apple executable, SQLite cache, watchlist, session, or credentials
should ever be committed to this repository.

## Running the adapter

```sh
cd /Users/sim/Dev/terminal-rs
TR_APPLE_STOCKS_CACHE=1 cargo run --release
TR_APPLE_STOCKS_CACHE=1 cargo run -p tr-data --example apple_stocks_probe
TR_APPLE_STOCKS_CACHE=1 cargo run -p tr-data --example apple_stocks_probe -- --route ADBE
```

Terminal automatically asks Apple's Stocks app to open missing symbols (using
its registered URL scheme), and waits briefly for cache updates. The terminal
uses eligible cached quotes where available, falling back to the existing
Yahoo/Alpaca routing for everything else. Only recent sparkline samples are
merged into 30m, 1h and 4h history, alongside the normal historical source.
Charts at other intervals always use existing Yahoo/Alpaca history.
Numeric Korean equity symbols such as `005930.KS` and `035900.KQ` are accepted.

Stock prices carry the cache's original refresh timestamp and can be delayed.
For open exchanges the adapter rejects cache quotes older than five minutes;
for closed exchanges it rejects records older than 30 minutes. Recent 10-minute
sparkline data must have been refreshed within ten minutes. No fake real-time
quotes, credentials, or calls to Apple's private service are generated by the adapter.

To disable the bridge, omit `TR_APPLE_STOCKS_CACHE=1` (or set it to `0`).
